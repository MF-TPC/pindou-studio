      📖 格物 · 使用说明书

      🎨 转换模式（照片 → 图纸）

      点左上「🎨 转换」，把照片拖进虚线框 / 点「📁 选择文件」/ Ctrl+V 粘贴。设好长宽（格数），程序自动把照片转成拼豆图案。右下「最大颜色数」可在导入时再调。

      🔍 导入图纸模式（从成品图纸读色号）

      点「🔍 导入图纸」进入 4 步向导：

      1. 框选 + 调格子：橙框框住「图案 + 编号圈」，蓝框框住下方「用量统计」。用 −/+ 调长宽（格数），让黑色虚线贴到图纸的格子线上；拖框边/角精修位置。
      2. 采样点偏移：每个格子中心有红点（采样点）。用 ↑↓←→ 把红点从格子中间印的色号字上移开，落到纯色区域，点「确认采样」。
      3. 背景清除：点格子可切换「背景 / 恢复」，把白底、编号圈都抹掉，点「确认背景」。
      4. 确定图纸：可设「最大颜色数」（0=不限），相近的颜色会自动合并。点「完成」退出。

      📍 辅助定位模式（摆珠子）

      切到「📍 辅助」，点「🔄 从转换结果导入」。设板子宽高、红线间距（每几格画一条红线）和起始偏移。屏幕按颜色分批提示，摆完一批点「✅ 下一批」；「🎯 专注」放大只看当前颜色，「↩ 撤销」回退。

      ✂️ 常用工具

      • 裁剪：切掉边缘；水平/垂直翻转、撤销。
      • 🧹 背景编辑：导入后点格子批量切换背景。
      • 💾 保存到仓库：把图纸存到本地（下次可从仓库恢复）。
      • 导出：下载 PNG / 打印 / JSON 备份。
      • 🌙 右上角切换明暗主题。

      提示：导入时建议用高清原图，格子线更容易对上；改完记得「确认」才生效。
