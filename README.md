# 格物 · Pindou Studio

一款纯静态、零依赖的拼豆（拼拼豆 / Perler Beads）工具，浏览器打开即用。能做三件事：**把照片变成图纸**、**把成品图纸读回矩阵**、**照着图纸帮你一颗颗摆完**。

**🌐 在线使用：https://mf-tpc.github.io/pindou-studio**

---

## 功能说明

### 🖼️ 转换图片（照片 → 图纸）

把任意图片转成拼豆图纸：

1. 左上选「🖼️ 转换图片」模式，把图片拖进虚线框、点虚线框、或 `Ctrl+V` 粘贴。
2. 在「转换设置」里填**长宽**（多少格），程序按比例缩放采样。
3. 颜色匹配到 **MARD 221 色板**（A~H + M 系列，221 色），逐格取主导色，用 CIELAB 色差（CIE76）找最近色。
4. 可以切换「符号 / 纯色块」两种显示，开关网格线。
5. 导出：下载 PNG（可放大）、打印、JSON 备份/恢复、复制到剪贴板。

### 🔍 导入图纸（成品图纸 → 矩阵）

把别人做好的成品图纸读回可编辑的矩阵。左上选「🔍 导入图纸」模式，然后拖拽 / 点击 / Ctrl+V 进图，进入 4 步向导：

1. **框选 + 调格子**：橙色框框住「图案 + 编号圈」，蓝色框框住下方「用量统计」。用 `−/+` 调格子数（长宽），让黑色虚线贴住图纸真实格子；拖框边/角精修位置。
2. **采样点偏移**：每个格子中心有红点。用 `↑↓←→` 把红点从格子中间印的**色号字**上移开，落到纯色区域，点「确认采样」。
3. **背景清除**：点格子切换「背景 / 恢复」，把白底、编号圈抹掉，点「确认背景」。
4. **确定图纸**：可设「最大颜色数」（0 = 不限），相近色自动合并，点「完成」退出。

> 思路是不靠全自动识别，而是把「网格、采样、背景」三件事交给用户精确控制，结果可靠。

### 📍 辅助定位（摆珠子）

从转换 / 导入的结果开始，帮你在实物板上逐颗摆放：

- **板子参数**：设板子宽高、红线间距（每几格一条红线）、起始偏移，有常用预设。
- **四色状态**：黑 = 板外不可用 / 白 = 待拼 / 红 = 已完成 / 绿 = 当前批。
- **按色分批**：自动按颜色拆成批次，摆完一批点「✅ 下一批」。
- **拖拽排序批次**：按住批次上下拖动，松手插入到目标位置（iOS 那种浮动拖动）。
- **偏远点检测**：自动标出离群孤立点及路径距离。
- **🎯 专注模式**：全屏放大只看当前颜色，底部直接控制批次。

### ✂️ 编辑 & 校验

- **改色**：点格子单格改色（移动端长按）；点图例可批量替换整图同色。
- **🧹 背景编辑**：点格子把误识别成颜色的背景恢复成空白，右侧统计实时更新。
- **↩ 撤销**：回退上一步编辑。
- **✅ 数量校验**：自动比对「图案实测用量」和「图例标注数量」，标出多 N / 少 N / ✓，一键「以图例为准」纠正。
- **💾 仓库**：把图纸存到本地（浏览器 localStorage），刷新后依然在，可随时载入继续。

### 📖 说明书

右上角「📖」按钮随时打开详细图文说明。

## 技术栈

纯原生 HTML + CSS + JavaScript，Canvas 渲染，无框架、无后端、无构建。

---

## 本地使用

浏览器直接打开 `index.html`，或起个静态服务器（部分浏览器对 `file://` 跨域资源有限制）：

```bash
python -m http.server 8000   # 然后访问 http://localhost:8000
```

---

## 部署

已配置 GitHub Actions 自动部署到 GitHub Pages，push 到 `master` 即可。想绑自定义域名：仓库 `Settings → Pages → Custom domain` 填域名，并把域名 CNAME 解析到 `mf-tpc.github.io`。
