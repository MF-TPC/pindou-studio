# 格物 · Pindou Studio

> 一款纯静态、零依赖、开箱即用的拼豆（Perler Beads / 拼拼豆）图纸转换与摆放辅助工具。

把一张照片变成可摆的拼豆图纸，或把别人的成品图纸精确「读」回色号矩阵，再用智能分批帮你一颗一颗摆完。**浏览器打开即用，无需安装、无需后端。**

## 📖 功能总览

### 🎨 转换模式（照片 → 图纸）

把任意图片转成拼豆图纸：

- **导入**：拖拽到虚线框、点「📁 选择文件」或 `Ctrl+V` 粘贴，均可。
- **尺寸**：设目标图纸长宽（格数），程序自动按比例缩放采样。
- **配色**：采用 **CIELAB 感知色差（CIE76 ΔE\*ab）直接匹配** 到 MARD 221 色板，逐格取主导色，最大程度保留原图色彩。
- **显示**：支持「符号」与「纯色块」两种显示模式，可开关网格线。
- **工具**：水平 / 垂直翻转、拖拽裁剪、撤销、🧹 背景编辑、💾 保存到仓库。
- **导出**：下载 PNG（可放大）、打印、JSON 备份 / 恢复、📋 复制到剪贴板。

### 🔍 导入图纸模式（成品图纸 → 色号矩阵）

把第三方软件导出的、或网上下载的**成品拼豆图纸**读回可编辑的矩阵。进入 4 步向导：

1. **框选 + 调格子**：橙色框框住「图案 + 编号圈」，蓝色框框住下方「用量统计」。用 `−/+` 调**长宽（格数）**，让黑色虚线网格贴合图纸真实格子；拖框边 / 角精修位置。
2. **采样点偏移**：每个格子中心有红色采样点，用 `↑↓←→` 把它从格子中间印的**色号字**上移开，落到纯色区域。
3. **背景清除**：点格子切换「背景 / 恢复」，把白底、编号圈全部抹掉。
4. **确定图纸**：可设「最大颜色数」（0 = 不限），相近色自动合并。

> 设计目标：不依赖脆弱的全自动识别，而是把「网格拟合、采样、背景」三件事交给用户精确控制，识别结果可靠可控。

### 📍 辅助定位模式（摆珠子）

从转换 / 导入结果开始，帮你在实物拼豆板上逐颗摆放：

- **板子参数**：设板子宽高、**红线间距**（每几格画一条红线）、起始偏移，并有常用预设。
- **四色状态**：黑 = 板外不可用 / 白 = 待拼 / 红 = 已完成 / 绿 = 当前批。
- **按色分批**：自动按颜色把图纸拆成批次，摆完一批点「✅ 下一批」。
- **偏远点检测**：自动标出「离群孤立点」及其路径距离，不用数格子。
- **🎯 专注模式**：全屏放大只看当前颜色，底部直接控制批次，双指缩放。

### ✂️ 编辑 & 校验

- **改色**：点击格子单格改色（移动端长按）；图例点击可**批量替换**整图同色。
- **背景编辑（🧹）**：扫雷式点格子，把误识别为颜色的背景恢复成空白。
- **数量校验（✅）**：自动比对「图案实测用量」与「图例标注数量」，标注多 N / 少 N / ✓，一键「以图例为准」纠正。
- **仓库（💾）**：把做好的图纸存到本地仓库，随时恢复继续。

### 📖 内置说明书

右上角「📖」按钮随时打开详细图文说明，覆盖全部功能的操作步骤。

## 🛠 技术栈

纯原生 **HTML + CSS + JavaScript**，Canvas 渲染，**零框架、零构建、零后端**。全站打包后即为静态文件。

色彩核心：

- **RGB → XYZ(D65) → CIELAB** 标准色度转换
- **CIE76 ΔE\*ab** 感知色差最近邻匹配
- **主导色提取**（每格直方图众数）+ **中心点采样**（避开格内文字）

## 📁 项目结构

```
pindou-studio/
├── index.html          # 主页面（含导入向导、说明书弹窗）
├── css/
│   └── style.css       # 全部样式（含明暗主题）
├── js/
│   ├── colormatch.js   # CIELAB 色彩转换 & CIE76 色差计算
│   ├── palettes.js     # MARD 221 色板数据
│   ├── converter.js    # 照片→矩阵：主导色 + 直接 Lab 匹配 + 限色
│   ├── dither.js       # 抖动（Floyd-Steinberg / Ordered）
│   ├── resizer.js      # 高低像素重采样
│   ├── board.js        # 拼豆板参数 & 红线坐标系
│   ├── importer.js     # 图纸导入：网格检测 / 图例解析 / OCR 辅助
│   ├── assistant.js    # 四色状态矩阵 & 批次流程 & 孤立点检测
│   ├── renderer.js     # Canvas 双模式渲染
│   ├── exporter.js     # PNG / 打印 / JSON 导出导入
│   └── app.js          # 主控制器（向导 / 采样 / 背景 / 仓库）
├── manifest.json       # PWA 清单
├── sw.js               # Service Worker（离线缓存）
└── .github/workflows/
    └── deploy.yml      # GitHub Pages 自动部署
```

## 🚀 本地使用

直接双击 `index.html` 用浏览器打开即可（部分浏览器对 `file://` 下跨域资源有限制，推荐起个静态服务器）：

```bash
# 任选其一
python -m http.server 8000      # 然后访问 http://localhost:8000
npx serve .
```
